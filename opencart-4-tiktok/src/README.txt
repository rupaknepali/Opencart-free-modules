TikTok Pixel and Events API for OpenCart 4
==========================================
Browser (TikTok Pixel): PageView, ViewContent, AddToCart, InitiateCheckout, Purchase.
Server (Events API): Purchase, deduplicated with the pixel by event_id.
Waits for consent from OpenCart's cookie bar or your own consent tool.

Install
1. Extensions > Installer: upload tiktok.ocmod.zip and click the green + button.
2. Extensions > Extensions > Modules: install "TikTok Pixel and Events API".
3. Edit: enter your pixel ID (and Events API access token), choose the consent mode, turn Status on and save.

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-tiktok-pixel-events-api/
