Full-Width Layout Position for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-full-width-layout-position/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
Adds a Content Full Width position to Design > Layouts, shown under the menu across the whole page.

Install: Extensions > Installer (upload fullwidth.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Full-Width Layout Position, Edit, turn Status on and save. Then add modules to Content Full Width in Design > Layouts.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
