# WebP Images

Serves WebP (or AVIF) versions of OpenCart's resized product, category and banner images automatically, without re-uploading anything. Keeps JPEG/PNG in emails.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`webp_images.ocmod.zip`](webp_images.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-webp-images/](https://webocreation.com/opencart-4-webp-images/) |

## Installation

1. Download [`webp_images.ocmod.zip`](webp_images.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **WebP Images**, then click **Edit**, set Status to Enabled and save.
