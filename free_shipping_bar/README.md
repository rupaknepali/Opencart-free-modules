# Free Shipping Progress Bar

Shows "Spend $X more for free shipping" in the cart and mini-cart, using the Free Shipping method's total, and suggests products that close the gap.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`free_shipping_bar.ocmod.zip`](free_shipping_bar.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-free-shipping-progress-bar/](https://webocreation.com/opencart-4-free-shipping-progress-bar/) |

## Installation

1. Download [`free_shipping_bar.ocmod.zip`](free_shipping_bar.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Free Shipping Progress Bar**, then click **Edit**, set Status to Enabled and save.
