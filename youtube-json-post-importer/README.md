# Import YouTube Videos as Posts (WordPress)

Imports YouTube videos as WordPress posts, sets the video thumbnail as featured image and assigns a category and author. Runs on a cron schedule.

## Installation

1. Zip the plugin folder (or copy it to `wp-content/plugins/`).
2. Activate it in **Plugins**.
