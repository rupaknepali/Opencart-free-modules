# Bulk Price & Stock CSV

Export products to CSV and update price, quantity and status in bulk from a CSV file, matched by product ID, model or SKU. Shows a preview of every change before anything is saved.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`product_csv.ocmod.zip`](product_csv.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-bulk-product-csv-import-export/](https://webocreation.com/opencart-4-bulk-product-csv-import-export/) |

## Installation

1. Download [`product_csv.ocmod.zip`](product_csv.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Bulk Price & Stock CSV**, then click **Edit**, set Status to Enabled and save.
