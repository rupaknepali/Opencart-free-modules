# YouTube Channel ID Finder (WordPress)

WordPress shortcode with a form that looks up a YouTube channel ID from a channel name.

| | |
|---|---|
| **Platform** | WordPress |
| **Type** | WordPress plugin |
| **Download** | [`youtube-channel-plugin.zip`](youtube-channel-plugin.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`youtube-channel-plugin.zip`](youtube-channel-plugin.zip).
2. In WordPress go to **Plugins > Add New > Upload Plugin**, upload the zip and activate it.
