# Wishlist Alerts & Reward Points

Emails customers when a product on their wishlist drops in price or comes back in stock (one email per customer), with daily cron, cooldown and newsletter-consent options. Optionally adds earned reward points automatically when an order is complete.

## Installation

1. Download [`wishlist_alerts.ocmod.zip`](wishlist_alerts.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Wishlist Alerts & Reward Points**, then click **Edit**, set Status to Enabled and save.
