Module Link in Admin Menu for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-module-link-admin-menu/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
Adds Extensions > Modules to the admin menu.

Install: Extensions > Installer (upload modulelink.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Module Link in Admin Menu, Edit, turn Status on and save.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
