Gift Wrap for OpenCart 4
========================
An order total extension: customers tick "Gift wrap my order (+$5.00)" and write a gift message,
in the cart (next to the coupon box) or on the checkout page. The price (with optional tax class)
is added to the order totals. The message is saved with the order and shown on the admin order
page, the invoice, the packing slip and in the customer's order confirmation email. Orders with
only downloadable products don't get the option.

Install
1. Extensions > Installer: upload giftwrap.ocmod.zip and click the green + button.
2. Extensions > Extensions > Order Total: install "Gift Wrap".
3. Edit: set the price, turn Status on and save.

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-gift-wrap/
