# Review Request Emails

Emails customers a few days after their order is complete and asks them to review what they bought, with one-click star ratings, a verified-buyer review page, an optional reminder and a report.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`review_request.ocmod.zip`](review_request.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-review-request-emails/](https://webocreation.com/opencart-4-review-request-emails/) |

## Installation

1. Download [`review_request.ocmod.zip`](review_request.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Review Request Emails**, then click **Edit**, set Status to Enabled and save.
