# GA4 Ecommerce Events

Sends Google Analytics 4 ecommerce events (view_item_list, view_item, add_to_cart, view_cart, begin_checkout, purchase) without editing theme files.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`ga4_ecommerce.ocmod.zip`](ga4_ecommerce.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-ga4-ecommerce-events/](https://webocreation.com/opencart-4-ga4-ecommerce-events/) |

## Installation

1. Download [`ga4_ecommerce.ocmod.zip`](ga4_ecommerce.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Analytics**, install **GA4 Ecommerce Events**, then click **Edit**, set Status to Enabled and save.
