# Multiple Flat Rates Shipping

Shipping method with several flat rates based on the order total, e.g. `500:10,250:20` (total:cost), per geo zone and tax class.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`multipleflatrates.ocmod.zip`](multipleflatrates.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`multipleflatrates.ocmod.zip`](multipleflatrates.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Shipping**, install **Multiple Flat Rates Shipping**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`multipleflatrates/`](multipleflatrates/).
