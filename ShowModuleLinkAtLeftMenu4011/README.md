# Show Module Link in Admin Left Menu

Adds a direct "Modules" link to the admin left menu so you can reach installed modules in one click.

| | |
|---|---|
| **Platform** | OpenCart 4.0.1.1 |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`showmoduleinleftmodule4011.ocmod.zip`](showmoduleinleftmodule4011/showmoduleinleftmodule4011.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`showmoduleinleftmodule4011.ocmod.zip`](showmoduleinleftmodule4011/showmoduleinleftmodule4011.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Show Module Link in Admin Left Menu**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`showmoduleinleftmodule4011/`](showmoduleinleftmodule4011/).
