Load More Products for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-load-more-products/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Written for 4.0.2.x and 4.1.x.

Install
1. Extensions > Installer: upload loadmore.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Modules: install Load More Products (this registers one event), then Edit, choose button or infinite scroll, turn Status on and save.

Works on category, search, specials and brand pages. The normal pagination links stay in the HTML for search engines and for visitors without JavaScript.
Free to use and modify. No attribution required.
