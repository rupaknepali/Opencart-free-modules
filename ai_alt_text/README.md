# AI Image Alt Text

Writes descriptive alt text for product images with Claude (vision), in every store language, and shows it on product pages and listings instead of the product name. Every text can be reviewed and edited before it goes live.

|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`ai_alt_text.ocmod.zip`](ai_alt_text.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-ai-image-alt-text-generator/](https://webocreation.com/opencart-ai-image-alt-text-generator/) |

## Installation

1. Download [`ai_alt_text.ocmod.zip`](ai_alt_text.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **AI Image Alt Text**, then click **Edit**, set Status to Enabled and save.

## Notes

- Requires an Anthropic API key (entered in the module settings).
