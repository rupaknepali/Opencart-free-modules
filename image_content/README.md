# Image Content

Displays an image with text content, with an option to switch the image position (left or right).

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`image_content.ocmod.zip`](image_content.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`image_content.ocmod.zip`](image_content.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Image Content**, then click **Edit**, set Status to Enabled and save.
