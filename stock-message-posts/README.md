# Low Stock Message

Shows "Only X left in stock – order soon" on products whose quantity is at or below a threshold you set.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`lowstock.ocmod.zip`](lowstock.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`lowstock.ocmod.zip`](lowstock.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Low Stock Message**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`lowstock/`](lowstock/).
