Cloudflare Turnstile for OpenCart 4 - free captcha extension by Webocreation
https://webocreation.com/opencart-4-cloudflare-turnstile-captcha/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Written for 4.0.2.x and 4.1.x.

Install
1. Extensions > Installer: upload turnstile.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Captchas: install Cloudflare Turnstile, then Edit.
3. Create a widget in the Cloudflare dashboard (Turnstile > Add widget), add your hostnames,
   paste the Site Key and Secret Key, turn Status on, save.
4. System > Settings > your store > Option: set Captcha to Cloudflare Turnstile and tick the pages to protect.

Test keys (staging): site key 1x00000000000000000000AA with secret 1x0000000000000000000000000000000AA always pass.
