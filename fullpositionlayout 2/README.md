# Full Width Layout Positions

Adds full-width top and bottom positions to Design > Layouts so modules can span the whole page width.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`fullwidthtopbottom.ocmod.zip`](fullwidthtopbottom.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-free-extension-to-add-full-width-position-in-layout/](https://webocreation.com/opencart-free-extension-to-add-full-width-position-in-layout/) |

## Installation

1. Download [`fullwidthtopbottom.ocmod.zip`](fullwidthtopbottom.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
