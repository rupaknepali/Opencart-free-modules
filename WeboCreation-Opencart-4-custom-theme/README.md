# Webocreation OpenCart 4 Theme

A starter custom theme for OpenCart 4, useful as a base for building your own theme.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`webocreation4.ocmod.zip`](webocreation4.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`webocreation4.ocmod.zip`](webocreation4.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Themes**, install **Webocreation OpenCart 4 Theme**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`webocreation4.ocmod/`](webocreation4.ocmod/).
