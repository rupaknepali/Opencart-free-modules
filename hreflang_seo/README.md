# Hreflang & Canonical SEO

Adds hreflang alternate links (with x-default) for every language, fills in missing canonical tags on the home and information pages, and adds noindex to search, compare, cart, checkout and account pages.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`hreflang_seo.ocmod.zip`](hreflang_seo.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-hreflang-canonical-multi-language-seo/](https://webocreation.com/opencart-hreflang-canonical-multi-language-seo/) |

## Installation

1. Download [`hreflang_seo.ocmod.zip`](hreflang_seo.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Hreflang & Canonical SEO**, then click **Edit**, set Status to Enabled and save.
