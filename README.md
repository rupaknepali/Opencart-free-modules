## Installing an extension

- **OpenCart 4:** Extensions > Installer > upload the `.ocmod.zip` > Install, then Extensions > Extensions > choose the type > Install > Edit > Enable.
- **OpenCart 3:** Extensions > Installer > upload the `.ocmod.zip`, then Extensions > Modifications > Refresh, then install and enable it in Extensions > Extensions.
- **OpenCart 2 / 1.5:** copy the files to the store root (vQmod files need vQmod installed).

Always test on a staging copy of your store and back up files and database first.
