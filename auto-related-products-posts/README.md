# Auto Related Products

Shows a "You may also like" block on product and cart pages, filled automatically when a product has no related products set by hand.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`autorelated.ocmod.zip`](autorelated.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`autorelated.ocmod.zip`](autorelated.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Auto Related Products**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`autorelated/`](autorelated/).
