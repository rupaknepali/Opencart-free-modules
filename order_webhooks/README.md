# Order Webhooks

Sends signed JSON webhooks (Standard Webhooks format) to your own URLs when an order is placed, an order status changes or a customer registers. Failed deliveries are retried by the OpenCart cron.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`order_webhooks.ocmod.zip`](order_webhooks.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-order-webhooks/](https://webocreation.com/opencart-4-order-webhooks/) |

## Installation

1. Download [`order_webhooks.ocmod.zip`](order_webhooks.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Order Webhooks**, then click **Edit**, set Status to Enabled and save.
