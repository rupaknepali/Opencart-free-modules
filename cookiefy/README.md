# Cookiefy (Cookie Consent)

Shows a cookie consent notice in the store footer with a configurable message.

| | |
|---|---|
| **Platform** | OpenCart 2.3.0.2 and 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`cookiefy3.ocmod.zip`](cookiefy3.ocmod.zip) |
| **Guide & support** | [webocreation.com/blog/cookiefy-opencart-store-free-module-version-2-3-0-2/](https://webocreation.com/blog/cookiefy-opencart-store-free-module-version-2-3-0-2/) |

## Installation

1. Download [`cookiefy3.ocmod.zip`](cookiefy3.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Cookiefy (Cookie Consent)**, then edit and enable it.

## Notes

- `cookiefy2.ocmod.zip` is for OpenCart 2.3.0.2, `cookiefy3.ocmod.zip` for OpenCart 3.
