# Common JS (OCMOD example)

Tutorial example that shows how an OCMOD can modify `menu.twig` and `common.js`.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`commonjs.ocmod.zip`](commonjs.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`commonjs.ocmod.zip`](commonjs.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).

## Notes

- **Demo only:** it adds an `alert('Changed')` to every page. Do not install on a live store.
