# All Products Listing

Displays all products of the store on a single page.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.3 |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`allproductslisting.ocmod.zip`](allproductslisting.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`allproductslisting.ocmod.zip`](allproductslisting.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **All Products Listing**, then click **Edit**, set Status to Enabled and save.
