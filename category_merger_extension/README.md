# Category Merger

Merges two categories: moves every product from the source category into the target category, then deletes the source category.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`category_merger.ocmod.zip`](category_merger.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`category_merger.ocmod.zip`](category_merger.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Category Merger**, then edit and enable it.

## Notes

- Merging cannot be undone. Back up your database first.
