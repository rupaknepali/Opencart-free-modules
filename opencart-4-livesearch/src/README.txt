Live Search for OpenCart 4
==========================
Product suggestions under the header search box as shoppers type: image, name and price (with the
special price), up to three matching categories, and a "See all results" link to the search page.

- Uses OpenCart's own product search, so suggestions match the search results page.
- Keyboard friendly: arrow keys, Enter and Escape; built as an ARIA combobox for screen readers.
- Waits 250 ms after the last keystroke, cancels outdated requests and remembers recent answers.
- No external search server and no jQuery plugin.

Install
1. Extensions > Installer: upload livesearch.ocmod.zip and click the green + button.
2. Extensions > Extensions > Modules: install "Live Search", click Edit, turn Status on and save.

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-live-search/
