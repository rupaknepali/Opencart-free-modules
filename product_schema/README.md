# Product Structured Data (JSON-LD)

Adds schema.org Product, Offer, AggregateRating, Review, MerchantReturnPolicy, OfferShippingDetails, BreadcrumbList, Organization and WebSite JSON-LD using events.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`product_schema.ocmod.zip`](product_schema.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-product-structured-data-json-ld/](https://webocreation.com/opencart-4-product-structured-data-json-ld/) |

## Installation

1. Download [`product_schema.ocmod.zip`](product_schema.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Product Structured Data (JSON-LD)**, then click **Edit**, set Status to Enabled and save.
