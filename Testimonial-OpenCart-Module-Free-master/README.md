# Feedback / Testimonials Module

Customers can write testimonials, admins approve them, and a module shows them on the storefront.

| | |
|---|---|
| **Platform** | OpenCart 2.2 – 2.3 |
| **Type** | OpenCart 2 extension (copy files) |
| **Guide & support** | [webocreation.com/blog/feedback-module-for-opencart-for-free-ecommerce-solution/](https://webocreation.com/blog/feedback-module-for-opencart-for-free-ecommerce-solution/) |

## Installation

1. Copy the contents of the folder (or its `upload/` folder) to the root of your OpenCart 2 store.
2. Go to **Extensions > Modules**, install the module, then edit and enable it.
3. Add the module to a layout in **System > Design > Layouts**.
