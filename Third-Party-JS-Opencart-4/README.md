# Third Party JS

Adds any third-party JavaScript (Google Analytics, tag managers, chat widgets, pixels) to every storefront page from the admin.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`thirdpartyjs.ocmod.zip`](thirdpartyjs.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`thirdpartyjs.ocmod.zip`](thirdpartyjs.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Analytics**, install **Third Party JS**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`thirdpartyjs/`](thirdpartyjs/).
