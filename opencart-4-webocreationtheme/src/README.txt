Webocreation Theme for OpenCart 4
=========================
A customizable theme built on OpenCart's own templates. Change colors, fonts and layout from the
admin with a live preview, no code needed:

- Colors: 22 color settings (brand, page, product cards, prices, top bar, header, menu,
  category icon bar, footer),
  7 presets (OpenCart Blue, Midnight dark, Forest, Sunset, Rose, Monochrome, Ocean), light or dark scheme.
- Typography: 19 Google Fonts or system fonts only (no requests to Google), separate body and
  heading fonts, base size, line height, heading weight, letter spacing, uppercase headings/buttons.
- Layout: page width, corner radius, button radius (pill buttons), card style, hover lift,
  show or hide wishlist and compare buttons.
- Header and footer: sticky header, menu, or both (the category bar shrinks to names while scrolling), compact header, centered logo, hide the top bar, your own footer line
  instead of "Powered by OpenCart", social icons, back-to-top button.
- Store style (1.1): a category icon bar instead of the text menu (automatic or chosen icons,
  or category images), five section heading styles, corner-ribbon badges, a breadcrumb
  band, boxed product tabs, quantity - and + buttons, a full-width Add to Cart, compact product
  cards and a white logo for colored headers. Electric color preset.
- Two home page modules (1.1): Webocreation Hero (slideshow from a banner with slide titles as tabs,
  plus a side panel of blog articles, specials or new products) and Webocreation Category Showcase
  (category heading with brand links, a tall promo banner and the category's products).
- Store footer (1.2): centered logo and store description, OpenCart's footer links in columns,
  contact details (phone, email, address from your store settings) with icons, a newsletter box
  that uses OpenCart's own newsletter subscription, and a bottom bar with the footer line and social icons.
- Custom CSS, with every setting available as a CSS variable (var(--wt-primary) and so on).
- Settings per store.

Install
1. Extensions > Installer: upload webocreationtheme.ocmod.zip and click the green + button.
2. Extensions > Extensions > Themes: install "Webocreation Theme", then Edit, turn Status on and save.
3. System > Settings > edit your store > General > Theme: choose "Webocreation Theme" and save.
4. Optional: Extensions > Extensions > Modules: install Webocreation Hero and Webocreation Category Showcase,
   create one of each, and add them to the Home layout in Design > Layouts.

Uses the default templates, so extensions keep working. Switching the store back to the
Default theme removes all Webocreation Theme styling instantly.

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-webocreation-theme/
