## Installation

1. Download [`test32.ocmod.zip`](test32.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Out of Stock Label (dev copy)**, then edit and enable it.
