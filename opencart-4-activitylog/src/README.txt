Admin Activity Log for OpenCart 4
=================================
Records who added, changed, copied or deleted what in the admin, and when: products, categories,
orders, customers, coupons, settings, users, layouts and extensions, with the before and after
value of every changed field (passwords and keys masked). Logins, failed logins and order status
changes from the admin order page are recorded too. Filter by user, action, type, date or keyword.
Old entries are deleted after the retention period (180 days by default).

Install
1. Extensions > Installer: upload activitylog.ocmod.zip and click the green + button.
2. Extensions > Extensions > Modules: install "Admin Activity Log".
3. Edit: Settings tab, turn Status on and save.

Uninstalling removes the events but keeps the log table.
Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-admin-activity-log/
