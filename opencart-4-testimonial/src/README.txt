Testimonials for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-testimonials-module/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
Manage customer testimonials in Catalog > Testimonials and show them in a slider. Multi-instance. Keeps testimonials from the OpenCart 3 tutorial tables.

Install: Extensions > Installer (upload testimonial.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Testimonials, add testimonials in Catalog > Testimonials, click + (Add) on the module to create a slider, then add it to a layout.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
