# Webocreation OpenCart 3 Theme (build)

Compiled assets (CSS, JS, images, Twig templates) of the Webocreation OpenCart 3 theme. Copy to `catalog/view/theme/webocreation/` and select it in System > Settings > Store > Option > Theme.
