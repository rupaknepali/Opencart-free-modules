# WordPress Posts in OpenCart

Shows the latest posts from a WordPress blog (via its URL) as a module on your OpenCart store.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`oc_module_wordpress_posts.ocmod.zip`](oc_module_wordpress_posts.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`oc_module_wordpress_posts.ocmod.zip`](oc_module_wordpress_posts.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **WordPress Posts in OpenCart**, then click **Edit**, set Status to Enabled and save.
