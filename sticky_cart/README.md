# Sticky Cart

Floating cart icon with item count that stays visible while scrolling (hidden on cart and checkout pages).

| | |
|---|---|
| **Platform** | OpenCart 1.5.x / 2.x (vQmod) |
| **Type** | vQmod modification |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Install [vQmod](https://github.com/vqmod/vqmod) on your store if it is not already installed.
2. Copy the files to the store root, keeping the folder structure (XML files go into `vqmod/xml/`).
