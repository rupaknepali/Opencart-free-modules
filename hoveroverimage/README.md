# Swap Image on Hover

Lets you choose a second image per product that is shown when shoppers hover over the product thumbnail.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`hoveroverimage.ocmod.zip`](hoveroverimage.ocmod.zip) |
| **Guide & support** | [webocreation.com/blog/swapping-image-when-hovering-over-in-products-opencart-free-module/](https://webocreation.com/blog/swapping-image-when-hovering-over-in-products-opencart-free-module/) |

## Installation

1. Download [`hoveroverimage.ocmod.zip`](hoveroverimage.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Swap Image on Hover**, then edit and enable it.
