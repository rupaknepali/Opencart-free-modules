Featured Categories for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-featured-categories-module/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
Shows the categories you choose, with images, as a module on any layout. Multi-instance.

Install: Extensions > Installer (upload featuredcategory.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Featured Categories, click + (Add) to create one, choose categories, save. Then add it to a layout in Design > Layouts.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
