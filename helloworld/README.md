# Hello World Module

Minimal OpenCart 3 module (admin settings + storefront output). A starting point for learning module development.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`helloworld.ocmod.zip`](helloworld.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`helloworld.ocmod.zip`](helloworld.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Hello World Module**, then edit and enable it.
