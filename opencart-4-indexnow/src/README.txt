IndexNow for OpenCart 4
=======================
Tells Bing, Yandex, Seznam, Naver and Yep about new, changed and deleted products, categories,
information pages and brands the moment you save them in the admin, with SEO URLs in every language.

Install
1. Extensions > Installer: upload indexnow.ocmod.zip and click the green + button.
2. Extensions > Extensions > Modules: install "IndexNow".
3. Edit: turn Status on, save, then click "Submit all URLs" once.

The key file ({key}.txt) is written to your store root. If the root isn't writable, the key is
served from index.php?route=extension/indexnow/module/indexnow.key instead.

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-indexnow/
