Size Chart for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-size-chart/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Written for 4.0.2.x and 4.1.x.

Install
1. Extensions > Installer: upload sizechart.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Modules: install Size Chart (this creates two tables and registers one event).
3. Edit: add a chart, paste the sizes (from a spreadsheet, or one row per line with | between cells), tick its categories and save.
4. Turn Status on in the Settings tab.

A "Size guide" link appears on product pages in those categories and opens the chart in a popup.
Uninstalling keeps your charts. To remove them: DROP TABLE oc_size_chart, oc_size_chart_to_category;
