# AI Shop Assistant

A chat assistant on every page that answers shoppers' questions by searching your catalog with Claude tool use. Read-only product tools, rate limits, store facts and a log of what customers ask.

## Installation

1. Download [`ai_shop_assistant.ocmod.zip`](ai_shop_assistant.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **AI Shop Assistant**, then click **Edit**, set Status to Enabled and save.

## Notes

- Requires an Anthropic API key (entered in the module settings).
