# PayPal Payments Standard

PayPal Payments Standard payment method for OpenCart 3.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`paypal-standard.ocmod.zip`](paypal-standard.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`paypal-standard.ocmod.zip`](paypal-standard.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Payments**, install **PayPal Payments Standard**, then edit and enable it.
