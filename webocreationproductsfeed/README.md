# Products Feed

Product data feed with Google category mapping and a data feed URL for shopping channels.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`webocreationproductsfeed.ocmod.zip`](webocreationproductsfeed.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`webocreationproductsfeed.ocmod.zip`](webocreationproductsfeed.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Feeds**, install **Products Feed**, then click **Edit**, set Status to Enabled and save.
