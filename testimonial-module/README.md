# Testimonials Slider

Multi-instance testimonials module with a slider, plus admin pages to add, edit and delete testimonials. Built as a module development tutorial.

## Installation

1. Copy the `admin/` and `catalog/` folders to the root of your OpenCart 3 store (they merge with the existing folders).
2. Go to **Extensions > Extensions > Modules**, install the module, then edit and enable it.
3. Add the module to a layout in **Design > Layouts** if it shows on the storefront.
