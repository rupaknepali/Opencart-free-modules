# Nepali Language Pack

Nepali (नेपाली) translation of the OpenCart admin and storefront.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`npl.ocmod.zip`](npl.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Upload [`npl.ocmod.zip`](npl.ocmod.zip) in **Extensions > Installer**, or copy the contents of `upload/` to your store root.
2. System > Localisation > Languages: add Nepali with code `npl`.
