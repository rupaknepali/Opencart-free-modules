Minimum Order Amount for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-minimum-order-amount/

Tested on OpenCart 4.1.0.4 (PHP 8.3).

Set a minimum order amount and/or minimum number of items per customer group (for example $25 for
retail customers, $500 and 20 items for wholesale). The cart shows how much more is needed and the
checkout is blocked until the minimum is reached.

Install
1. Extensions > Installer: upload minorder.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Modules: install Minimum Order Amount, then Edit, set the rules,
   turn Status on and save.
