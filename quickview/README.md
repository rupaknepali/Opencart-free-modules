# Product Quick View

Adds a Quick View button to every product card that opens the product in a popup with add-to-cart.

| | |
|---|---|
| **Platform** | OpenCart 4.0.2.x – 4.1.x (tested on 4.1.0.4, PHP 8.3) |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`quickview.ocmod.zip`](quickview.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-product-quick-view/](https://webocreation.com/opencart-4-product-quick-view/) |

## Installation

1. Download [`quickview.ocmod.zip`](quickview.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Product Quick View**, then click **Edit**, set Status to Enabled and save.

## Notes

- Installing the module registers two events; nothing needs to be added to layouts.
- Products with required options or subscriptions show "Choose options" in the popup and link to the product page.
