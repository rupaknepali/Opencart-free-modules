Estimated Delivery Date for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-estimated-delivery-date/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Written for 4.0.2.x and 4.1.x.

Install
1. Extensions > Installer: upload estdelivery.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Modules: install Estimated Delivery Date (this registers one event).
3. Edit: set your cut-off time, dispatch days, holidays and delivery times, turn Status on and save.

Dates use the time zone in System > Settings > Local. The message appears on product pages above the Add to Cart form.
