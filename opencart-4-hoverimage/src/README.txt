Swap Image on Hover for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-swap-image-on-hover/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
Shows a product's first additional image when shoppers hover over its card.

Install: Extensions > Installer (upload hoverimage.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Swap Image on Hover, Edit, turn Status on and save.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
