# Show All Products (v1)

Lists all products of the store on one page and adds a link to it in the top menu.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`Archive.zip`](Archive.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`Archive.zip`](Archive.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).

## Notes

- Same extension as [show-all-products](../show-all-products/); prefer that folder.
