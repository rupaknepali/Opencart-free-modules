# Edit Products from the Products List

Edit product name, model, price, quantity and status directly in the admin products list (inline editable table) without opening each product.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`editfromproductslist.ocmod.zip`](editfromproductslist.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`editfromproductslist.ocmod.zip`](editfromproductslist.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Edit Products from the Products List**, then edit and enable it.
