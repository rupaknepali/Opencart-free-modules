# Frequently Bought Together

Shows products that customers often buy together with the current product, based on your own orders.

| | |
|---|---|
| **Platform** | OpenCart 4.0.2.x – 4.1.x (tested on 4.1.0.4, PHP 8.3) |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`boughttogether.ocmod.zip`](boughttogether.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-frequently-bought-together/](https://webocreation.com/opencart-4-frequently-bought-together/) |

## Installation

1. Download [`boughttogether.ocmod.zip`](boughttogether.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Frequently Bought Together**, then click **Edit**, set Status to Enabled and save.
4. Design > Layouts > Product: add **Frequently Bought Together** to *Content Bottom* and save.

## Notes

- Suggestions come from orders with a "processing" or "complete" status (System > Settings > Option).
- A product page shows the block once another product shares at least "Minimum shared orders" orders with it.
- Results are cached for an hour.
