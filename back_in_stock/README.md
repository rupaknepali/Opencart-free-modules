# Back-in-Stock Notifications

Adds a "Notify me when it's back" form to out-of-stock product pages, emails subscribers when stock returns, and reports the most wanted products and recovered sales.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`back_in_stock.ocmod.zip`](back_in_stock.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-back-in-stock-notifications/](https://webocreation.com/opencart-4-back-in-stock-notifications/) |

## Installation

1. Download [`back_in_stock.ocmod.zip`](back_in_stock.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Back-in-Stock Notifications**, then click **Edit**, set Status to Enabled and save.
