# AI Product Description Generator

Generates SEO-friendly product descriptions with AI from the product form, using a configurable prompt.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`ai_description_generator.ocmod.zip`](ai_description_generator.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`ai_description_generator.ocmod.zip`](ai_description_generator.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **AI Product Description Generator**, then click **Edit**, set Status to Enabled and save.
4. The unpacked source is in [`ai_description_generator/`](ai_description_generator/).

## Notes

- Requires an AI provider API key (entered in the module settings).
