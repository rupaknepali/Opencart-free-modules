Recently Viewed Products for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-recently-viewed-products/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Written for 4.0.2.x and 4.1.x.

Install
1. Extensions > Installer: upload recentlyviewed.ocmod.zip, then click the green Install button.
2. Extensions > Extensions > Modules: install Recently Viewed Products (this registers one event), then Edit and turn Status on.
3. Design > Layouts: add Recently Viewed Products to the layouts you want (Product, Category, Home...), usually Content Bottom.

The history is kept in a cookie (oc_recently_viewed) that holds product IDs only, for 30 days.
