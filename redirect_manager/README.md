# Redirect Manager

Manage 301/302 redirects, log 404 (not found) URLs and import redirects in bulk.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`redirect_manager.ocmod.zip`](redirect_manager.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`redirect_manager.ocmod.zip`](redirect_manager.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Redirect Manager**, then click **Edit**, set Status to Enabled and save.
