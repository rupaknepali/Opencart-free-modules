# CSV Review Import

Imports product reviews from a CSV file, matched by product model. A [sample CSV](sample_reviews.csv) is included.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`import-reviews.ocmod.zip`](import-reviews.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`import-reviews.ocmod.zip`](import-reviews.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **CSV Review Import**, then edit and enable it.
