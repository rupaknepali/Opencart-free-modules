Buy It Again for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-buy-it-again/

Tested on OpenCart 4.1.0.4 (PHP 8.3).
- An "Add all to cart" button on each order in My Account > Order History: every item, same options.
- A "Buy it again" block of products the logged-in customer has bought before, on My Account and
  on any layout (Design > Layouts > add "Buy It Again").

Install: Extensions > Installer (upload buyagain.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install Buy It Again, Edit, turn Status on and save.
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
