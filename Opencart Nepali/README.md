# Nepali Language Pack (ne) + Flags

Alternative Nepali translation using the `ne` language code, plus a set of country flag images (`flags/`, `flags.zip`).

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`opencartnepali.ocmod.zip`](nepali/opencartnepali.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Upload [`opencartnepali.ocmod.zip`](nepali/opencartnepali.ocmod.zip) in **Extensions > Installer**, or copy the contents of `upload/` to your store root.
2. System > Localisation > Languages: add Nepali with code `ne`.
