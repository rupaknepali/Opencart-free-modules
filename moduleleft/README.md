# Show Module Link in Admin Left Menu

OCMOD that adds a direct "Modules" link to the admin left menu.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`moduleleft.ocmod.zip`](moduleleft.ocmod.zip) |
| **Guide & support** | [webocreation.com/blog/show-module-link-left-menu-admin-opencart-ocmod/](https://webocreation.com/blog/show-module-link-left-menu-admin-opencart-ocmod/) |

## Installation

1. Download [`moduleleft.ocmod.zip`](moduleleft.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).

## Notes

- For OpenCart 4 use [ShowModuleLinkAtLeftMenu4011](../ShowModuleLinkAtLeftMenu4011/).
