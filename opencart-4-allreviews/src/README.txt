All Reviews Page for OpenCart 4 - free extension by Webocreation
https://webocreation.com/opencart-4-all-reviews-page/

Tested on OpenCart 4.1.0.4 (PHP 8.3). Converted from the OpenCart 3 version.
A page listing every approved product review, with a footer link.

Install: Extensions > Installer (upload allreviews.ocmod.zip, click Install), then
Extensions > Extensions > Modules: install All Reviews Page, Edit, turn Status on and save. The page is index.php?route=extension/allreviews/product/allreviews
No core files are changed (OpenCart events only).
Free to use and modify. No attribution required.
