# Voice Search

Adds a microphone button to the storefront search box so shoppers can search by voice (Web Speech API, supported browsers only).

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`voicesearch.ocmod.zip`](voicesearch.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`voicesearch.ocmod.zip`](voicesearch.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).

## Notes

- Modifies `catalog/view/theme/default/template/common/search.twig`; custom themes may need the path adjusted.
