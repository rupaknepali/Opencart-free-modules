# Google Sitemap

XML sitemap of products, categories, manufacturers and information pages for Google and other search engines.

| | |
|---|---|
| **Platform** | OpenCart 4.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`webocreationgooglesitemap.ocmod.zip`](webocreationgooglesitemap.ocmod.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`webocreationgooglesitemap.ocmod.zip`](webocreationgooglesitemap.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Feeds**, install **Google Sitemap**, then click **Edit**, set Status to Enabled and save.
