# AI Shopping Product Feed

Builds a product feed in the OpenAI product feed format (JSONL, gzip) for ChatGPT shopping and other AI shopping agents: prices, availability, GTIN/MPN, images, categories, variants and reviews. Regenerated by the OpenCart cron.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`ai_product_feed.ocmod.zip`](ai_product_feed.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-ai-shopping-product-feed-chatgpt/](https://webocreation.com/opencart-ai-shopping-product-feed-chatgpt/) |

## Installation

1. Download [`ai_product_feed.ocmod.zip`](ai_product_feed.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **AI Shopping Product Feed**, then click **Edit**, set Status to Enabled and save.
