Order Export for OpenCart 4
===========================
Download orders as CSV for Excel or Google Sheets: filter by date, status and store,
one row per order (with every order total as a column) or one row per product.
Also adds an Export CSV button to Sales > Orders that exports the filtered list.

Install
1. Extensions > Installer: upload orderexport.ocmod.zip and click the green + button.
2. Extensions > Extensions > Modules: install "Order Export".
3. Sales > Export Orders (or Edit on the module).

Tested on OpenCart 4.1.0.4.
Guide: https://webocreation.com/opencart-4-export-orders-csv/
