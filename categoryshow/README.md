# Featured Categories

Shows selected categories as a featured categories module on any layout.

| | |
|---|---|
| **Platform** | OpenCart 3.0.x |
| **Type** | OpenCart 3 extension / OCMOD |
| **Download** | [`categoryshow.ocmod.zip`](categoryshow.ocmod.zip) |
| **Guide & support** | [webocreation.com/blog/opencart-show-selected-categories-as-featured-module-free/](https://webocreation.com/blog/opencart-show-selected-categories-as-featured-module-free/) |

## Installation

1. Download [`categoryshow.ocmod.zip`](categoryshow.ocmod.zip).
2. In the admin go to **Extensions > Installer** and upload the zip.
3. Go to **Extensions > Modifications** and click **Refresh** (top right).
4. Go to **Extensions > Extensions**, choose **Modules**, install **Featured Categories**, then edit and enable it.
