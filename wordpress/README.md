# Category Popular Posts (WordPress)

WordPress widget that shows popular posts per category.

| | |
|---|---|
| **Platform** | WordPress |
| **Type** | WordPress plugin |
| **Download** | [`category-popular-posts.zip`](category-popular-posts.zip) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Download [`category-popular-posts.zip`](category-popular-posts.zip).
2. In WordPress go to **Plugins > Add New > Upload Plugin**, upload the zip and activate it.
