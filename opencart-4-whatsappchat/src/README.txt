WhatsApp Chat Button for OpenCart 4 (4.0.2.x - 4.1.x)
A floating click-to-chat button and an "Ask on WhatsApp" button on product pages, with the
product name and link pre-filled, opening hours and a greeting bubble. Uses plain wa.me links.

Install: Extensions > Installer > Upload whatsappchat.ocmod.zip, then Extensions > Extensions >
Modules > WhatsApp Chat Button > Install and Edit. Enter your number with the country code.
Guide: https://webocreation.com/opencart-4-whatsapp-chat-button/
