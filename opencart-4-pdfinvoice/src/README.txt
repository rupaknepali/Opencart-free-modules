PDF Invoice for OpenCart 4 (tested on 4.1.0.4)
https://webocreation.com/opencart-4-pdf-invoice/

Install: Extensions > Installer > upload pdfinvoice.ocmod.zip > install (+).
Then Extensions > Extensions > Modules > PDF Invoice > install, edit, turn Status on and save.
Emails need a mail engine in System > Settings > edit store > Mail.
No core files are changed. Uninstalling removes the events and keeps the send log.
