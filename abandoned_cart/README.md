# Abandoned Cart Recovery

Captures abandoned carts, sends up to 3 reminder emails with a one-click restore link and an optional unique coupon, and reports recovered revenue.

| | |
|---|---|
| **Platform** | OpenCart 4.1.0.x |
| **Type** | OpenCart 4 extension (`.ocmod.zip`, uses Events) |
| **Download** | [`abandoned_cart.ocmod.zip`](abandoned_cart.ocmod.zip) |
| **Guide & support** | [webocreation.com/opencart-4-abandoned-cart-recovery/](https://webocreation.com/opencart-4-abandoned-cart-recovery/) |

## Installation

1. Download [`abandoned_cart.ocmod.zip`](abandoned_cart.ocmod.zip).
2. In the admin go to **Extensions > Installer**, upload the zip, then click the green **Install** button.
3. Go to **Extensions > Extensions**, choose **Modules**, install **Abandoned Cart Recovery**, then click **Edit**, set Status to Enabled and save.
