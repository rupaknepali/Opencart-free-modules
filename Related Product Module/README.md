# Related Products Module

Shows related products as a module that can be placed in any layout position.

| | |
|---|---|
| **Platform** | OpenCart 2.0 – 2.1 |
| **Type** | OpenCart 2 extension (copy files) |
| **Guide & support** | [webocreation.com](https://webocreation.com) |

## Installation

1. Copy the contents of the folder (or its `upload/` folder) to the root of your OpenCart 2 store.
2. Go to **Extensions > Modules**, install the module, then edit and enable it.
3. Add the module to a layout in **System > Design > Layouts**.
